# Image-Processing-with-C-
A simple image processing application using object-oriented programming and custom image filters.

## Overview
This project implements basic image processing operations using C++.

## Features
- Image representation using a 2D pixel array
- Pixel access and modification
- Basic image processing operations

## Technologies
- C++
- Object-Oriented Programming

## Purpose
This project was developed as part of my programming studies to practice C++ programming and object-oriented design.
